# 产品与范围

## 产品定位

Knowledge Core 是一个面向个人创作者与小团队的知识写作、管理、协作和发布平台。品牌名称固定为 **Knowledge Core**，不沿用旧站点 HappyLadySauce 的产品品牌。

旧站 `happyladysauce.cn` 仅作为视觉参考，不做内容迁移，也不与新平台共享运行时或数据域。

## 用户与设备

- 首要用户：个人创作者、独立作者、小型协作团队。
- 主要形态：桌面优先的响应式 Web。
- 移动端：支持浏览与基础操作，不单独开发原生 App。
- 初始规模假设：约 1,000 个注册用户、100 并发、单文档最多 20 位协作者。

## 核心闭环

1. 公开访问作者主页、文章、标签、归档和 RSS。
2. 注册、邮箱验证、登录、刷新会话、全端登出、忘记密码、停用账号。
3. 在 Studio 中创建和编辑文档，使用个人文件夹组织内容。
4. 文档可发布为公开文章，也可保留为私有资料。
5. 公开文章支持评论、回复、点赞、收藏、关注、通知、举报与治理。
6. 写作助手与知识问答使用用户授权的文档作为上下文。

## 已确认的产品决策

### 个人文件夹

- 文件夹只负责个人组织，不承担权限语义。
- 支持嵌套，最大深度 8 层。
- 删除文件夹时，内容移动到父级，而不是级联删除。
- 已共享文档也可以被个人归档到自己的文件夹。

### 编辑器与协作

- 文档中心编辑器采用 Tiptap / ProseMirror。
- 支持 slash command、浮动工具栏和文档画布。
- 协作数据使用 Yjs；实时协作由 Knowledge-Core Collaboration 服务承载。
- 协作权限与文档访问权限由后端裁决，前端不自行推断权限。

### 主题与语言

- 支持浅色、深色和跟随系统。
- UI 首期支持简体中文与英文。
- 视觉方向为专业科技特效风：深石墨底色、电光蓝/紫渐变、克制的网格和光晕、暖琥珀色强调。
- 编辑器画布保持低干扰，不使用持续动画或过度发光。

### AI

- 提供写作助手与知识库问答。
- 支持双路 OpenAI-compatible 接口：chat 与 embedding。
- 登录用户的 AI 对话持久化，并归属当前账号。
- 公共 AI 查询范围为当前作者的全部公开文章。
- 私有文档默认自动索引，并在 UI 中明确提示。
- 匿名公共 AI 使用 Turnstile + IP 配额；服务端必须验证 token。

### 社区治理

- 评论支持回复、点赞、举报和审核。
- 提供站内通知，不发送邮件通知。
- 举报进入审核队列，需保留处理状态和审计记录。

## 非目标

- 不迁移旧站内容。
- 不在第一阶段实现 AI、社区或完整实时协作。
- 不在浏览器保存 access token 或 refresh token。
- 不把个人文件夹当作共享权限模型。
